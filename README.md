# NAS 字幕弹幕合成工具

选择影片，自动识别标题、查找台词字幕与弹幕，确认后生成一条「字幕加弹幕」ASS，保存到影片原目录。

适合极影视等只能单选字幕、但能够渲染 ASS 滚动效果的播放器。工具在 Windows 电脑上运行；电视加载生成的字幕即可。运行时只需要一个 Python 源文件：`nas_danmaku.py`。

**当前版本：2.6.2。B 站优先直连，合并 XML 与全部分段弹幕，避免公共备用接口条数过少。** 先核实电影的各个弹幕来源，标明实际条数，只能选择已取得的弹幕，切换直接使用本机缓存。内置和自定义屏蔽规则统一展示，可修改、停用、删除并测试命中，重启后保留。弹幕连续接入，默认只在顶部 1/4 显示小字号滚动弹幕，支持多个字幕来源自动切换，在电脑本地合成，再写回 NAS。弹弹play官方接口申请已提交，正在审核，当前版本尚未连接其官方在线 API。当前自动弹幕获取使用 B 站直连接口及下文列出的第三方公共来源，无法保证每部影片均能匹配。

## 使用方法

1. 安装 Python 3.10 或更新版本，安装时保留 Tkinter，并将 Python 加入 PATH。
2. 安装 [FFmpeg](https://ffmpeg.org/download.html)，确认 `ffmpeg` 和 `ffprobe` 能在终端运行。影片探测及内封文字字幕提取需要它们。
3. 下载本仓库的 `nas_danmaku.py`，双击，或运行：

   ```powershell
   python nas_danmaku.py
   ```

4. 选择影片，等待标题、字幕及弹幕来源显示；核对电影版本、年份和片长。「找到的电影弹幕」标明已取得的来源与条数，下方「来源」可直接切换缓存，「弹幕设置」可调显示效果。识别有误时可修正标题重查，也可手动补选字幕或弹幕文件。
5. 点击「确认合成」。先在电脑本地生成 ASS，再写回影片目录，成品统一命名为 `弹幕版-影片文件名.ass`（保留影片完整文件名，去掉视频扩展名）。例如 `楚门的世界.1998.mkv` 对应 `弹幕版-楚门的世界.1998.ass`。已有同名文件时自动追加 `-v2`、`-v3`，不覆盖原文件。写回失败时本机成品仍保留，恢复 NAS 连接后点「重试写回 NAS」。
6. 在电视播放器中选择生成的这一条字幕。台词和弹幕已合在一起。

也可将影片路径作为参数：

```powershell
python nas_danmaku.py "Z:\电影\影片.mkv"
```

不需要安装第三方 Python 模块。不要将 GitHub 项目页面另存为 `.py`；请下载源文件的原始内容或使用仓库的 Download ZIP。

## 外挂字幕与本地合成

默认顺序是：影片目录内的外挂中文字幕 → 迅雷 → SubHD → 射手指纹 → SubtitleCat。前一个来源已取得可用字幕就停止，失败或没有匹配才切换，避免每次都查询所有站点。每个来源的失败原因会保留在界面日志。检测到内封中文字幕也会继续搜索在线外挂，不再直接进入耗时的远程提取。

SubHD 使用网站正常的准备下载、下载页和下载接口流程，会保留本次公开访问的会话 Cookie；遇到验证码、登录要求或拒绝访问时停止该来源。ZIP 字幕包直接用 Python 标准库读取；7z/RAR 包使用本机 `7z`/`7zz`（或 `Program Files/7-Zip/7z.exe`）。未安装 7-Zip 时提示并继续其他来源，运行仍只需一个 `.py` 文件。压缩包只读取文字字幕，不把其中的路径解压到文件系统；最多 100 项、解压总量 32 MB。

SubtitleCat 只下载页面已经提供的简体/繁体中文字幕，不发起翻译任务、不使用英文替代；结果明确标注“可能机翻”，作为最后备用，请检查翻译质量和时间轴。网页型来源对页面结构变化较敏感，不保证长期可用。

窗口顶部的「网页找字幕」可打开 ASSRT（伪射手）、SubHD 和 SubtitleCat 的片名搜索页，手动下载后用「补选字幕」导入。ASSRT 网页入口与原射手指纹 API 是不同来源，当前没有使用 ASSRT API Token，也不将网页补选算作自动来源。此次核实中 A4K 连接失败、字幕库公开地址返回 404，因此未加入自动列表。

内封字幕保存在视频容器内部，提取时可能需要扫描大量视频数据。只有手动点击「使用内封」并确认合成后才提取；使用在线字幕时不会下载整部电影。影片初始信息探测限时 20 秒，失败后继续按片名查找，片长显示为未知。

在线结果过滤冲突片名、年份、分碟标记和明显不合理的字幕结束时间，优先简体中文，最多下载三份可用候选。按片名找到字幕并不保证发行版本和时间轴完全一致，仍需核对。射手指纹没有命中只表示该文件指纹没有匹配，不代表电影没有字幕资源。

识别时，台词和弹幕写入电脑的 `%LOCALAPPDATA%\NasDanmaku\cache\movie-*`。合成和弹幕排版均在本机完成；NAS 只需在初始读取及最后核对影片、写回时可用。已取得字幕和弹幕后，即使 NAS 临时离线，也能生成并保留本机成品。写回先使用 `.part` 临时文件，完整关闭后才发布为 ASS，失败不会把半份文件显示成可选字幕。

「重试写回 NAS」只复制已经生成的文件，保留原先选定的影片和参数。关闭窗口后本机文件仍保留，但重试任务不会自动恢复；可按界面显示的路径手动复制成品，或补选缓存字幕和弹幕重新处理。缓存不自动删除，可在不再需要时清理对应 `movie-*` 目录。

## 弹幕来源与显示设置

选中一部候选电影后，查询其已有链接的所有受支持平台：腾讯视频、爱奇艺、哔哩哔哩、优酷、芒果 TV。最多三个平台同时查询，B 站优先直连，按弹幕 ID 合并旧 XML 与全部六分钟分段，支持 ep、BV/av 及分 P 链接；分段同时最多三个请求。直连完全失败才尝试公共库；部分接口失败时保留已取得数据，来源说明标出“部分获取”及原因。其他平台先请求主公共弹幕库，失败再请求备用库。首次识别会查询默认电影候选；其他候选标为「来源待查询」，选中后再查，避免一次下载所有相似片名的弹幕。

电影候选旁标明已取得的来源和条数；「来源」下拉框只包含实际取得并缓存的弹幕，例如 `腾讯视频 · 12,345 条`。下方汇总各平台结果，失败标为「未取得」，具体接口、解析或缓存失败原因见日志；不会把查询失败写成确定的零条资源。条数是解析后的原始条数，合成时还会过滤、去重、限流及按片长裁剪。

取得的各来源分别保存在本机缓存中。默认按平台顺序选第一个成功来源，切换立即复用缓存，不再查询接口、读取 NAS 或下载台词；选回已查询过的电影也复用其结果。「重查来源」只重试未取得的项目，保留成功来源及当前选择。新电影与不同版本的缓存按标题、年份和平台链接区分，切换未取得弹幕的新候选时清空旧选择，避免串用。

来源查询结果保留在当前会话，重启后不会自动恢复下拉列表，但本机 `danmaku-平台名*.json` 缓存文件仍保留，可手动补选。修改过滤和显示设置后可直接重新合成。

默认设置：

| 设置 | 默认值 |
| --- | --- |
| 显示区域 | 屏幕顶部 25%，下方 75% 不放弹幕 |
| 字号 | 32，以 1080p 为基准，随字幕画布高度缩放 |
| 不透明度 | 80% |
| 速度 | 1×，每条显示 12 秒；2× 为 6 秒，0.5× 为 24 秒 |
| 同屏上限 | 6 条；显示区域放不下时自动减少 |
| 类型 | 保留滚动和彩色，屏蔽固定弹幕 |
| 防挡字幕 / 过滤重复 | 开启 |

「弹幕设置」参考常用视频播放器：拖动显示区域、不透明度、字号、速度滑块，并通过勾选项屏蔽滚动/固定/彩色弹幕；下方提供 16:9 比例示意。防挡字幕会把实际区域限制在顶部 68% 以内。固定弹幕手动开启后，其顶部/底部位置也只在所选显示区域内；所有类型共享行占用，避免互相重叠。去重是文本重复过滤，不是 AI 人物避让或智能语义过滤。

2.3.1 修复弹幕分批出现：同向弹幕不再独占整行直至离场，按估算文字宽度、移动速度检查入口间距及后续追赶，允许一行同时容纳多条。进入节奏按「显示时长 / 同屏上限」分散，避免瞬间填满后一起等待；固定弹幕和相反方向仍保守地等待空行。超密条目直接过滤，不把原始评论时间向后排队；源数据本身没有弹幕的时段仍保持空白。

调整后点击「应用设置」，再「确认合成」。字号、区域等显示设置和内置过滤总开关保留在当前窗口内，重新启动恢复默认；屏蔽规则列表及各条开关会保存在本机。已生成的字幕不会随设置变化自动更新，新合成仍使用版本号避免覆盖。原台词字幕的字号、样式和透明度保持不变。手动导入的 ASS 弹幕保留已有排版，只支持时间偏移，显示设置按钮会禁用；在线弹幕与 XML/JSON 才能重新排版。

### 垃圾弹幕过滤

「弹幕设置」中的「过滤垃圾弹幕」默认开启。本机规则在排版前过滤，避免垃圾条目占用连续进入和同屏名额；不调用云端 AI，也不上传弹幕内容。合成日志单独列出内置规则和自定义规则屏蔽的条数，均包含在总过滤数量内。

| 类别 | 会过滤的例子 |
| --- | --- |
| 日期/时间打卡 | `2026年10月7日观看`、`2026.10.7打卡`、`现在是23:58`、`2026还有人看吗` |
| 报几刷/占位 | `第一次观看`、`二刷`、`签到`、`前排` |
| 陪同观看打卡 | `今天和女朋友一起看`、`我和张三一起看这部电影` |
| 找人聊天 | `在吗？在吗？`、`有人在看吗`、`在的举个手` |
| 重复字符/明显广告 | `AAAAAAA`、`111111111`、`加QQ群123456789`、`关注我领取资源` |

匹配副本兼容全角、空格、零宽字符和常见简繁写法；原文和缓存保持原样。默认规则优先识别完整打卡句式，会保留 `1998年上映的电影`、`12:34这个镜头真好`、`二刷才注意到这里的摄像头`、`哈哈哈哈哈哈` 等正常讨论或反应。规则不是语义理解，仍可能漏掉新句式或误判；可修改或停用对应规则。

打开「弹幕设置 → 屏蔽规则（内置＋自定义）」，六条内置规则与新增规则放在同一列表，展示来源、名称、开关和匹配方式。选择一条即可查看或修改用途说明、屏蔽/保留示例及实际匹配内容，也可停用、删除或恢复全部默认。日期和观看打卡是组合规则，各组成表达式通过下拉列表逐项查看和编辑。说明与示例不参与匹配；实际过滤使用列表中的规则，删除后不会偷偷回退到内置版本。

| 方法 | 怎么用 |
| --- | --- |
| 普通关键词 | 每条规则填一个词，如 `加群`，包含该词就屏蔽；日常添加优先用它 |
| 正则：部分匹配 | 匹配写法规律，例如 `\d{4}年` 匹配“四位数字＋年”；也会命中正常的年份讨论，请先测试 |
| 正则：整句匹配 | 去掉标点后整句符合才屏蔽，例如 `在吗` 匹配 `在吗？`，保留 `他在吗` |

正则表达式就是描述文字规律的写法：`\d` 表示数字、`{4}` 表示重复四次、`A|B` 表示 A 或 B。匹配会忽略大小写、空格和常见简繁差异。正则及组合规则只检查规范化后不超过 180 字的弹幕；普通关键词没有这个长度限制。

输入一句弹幕点「测试这句弹幕」，会显示是否屏蔽及所有命中的规则名称。测试遵循当前内置总开关和各条开关；自定义规则独立于内置总开关。正则写错会指出具体规则；修改过的正则在独立进程中运行，测试限时 3 秒、合成过滤限时 15 秒，超时会提示停止，不会假装处理成功。

点「保存规则」返回，再点「应用设置」，规则才生效并保存到 `%LOCALAPPDATA%\NasDanmaku\block-rules.local.json`；重启后保留。修改已有配置前自动备份到 `D:\临时备份\NasDanmaku`（非 Windows 使用配置目录下的 `backups`）。备份或写入失败时不应用新规则；配置损坏会提示并暂用默认，不自动覆盖原文件。最多 150 条规则，每个匹配字段最多 2000 字；删除全部规则后保存代表不做内容屏蔽。

原始获取预览尚未过滤，过滤只作用于重新合成的在线/XML/JSON 弹幕；台词字幕和手动导入的已排版 ASS 不参与内容过滤。修改规则后需重新合成，电视再选择新文件。

分类参考公开项目 [Bilibili-Block-List](https://github.com/jnxyp/Bilibili-Block-List) 与 [bilibili-danmaku-shield](https://github.com/Ailitonia/bilibili-danmaku-shield) 的说明；本工具按电影观看需求自写规则，没有直接引入其整份屏蔽词表，也没有实时订阅远程规则。

## 处理进度

2.0.3 改用当前步骤的实际进度，取消来回滑动的等待动画。切换步骤时进度重新计算，界面同时显示步骤名称、计量数据和耗时；不是整个任务的预计完成百分比。

| 当前步骤 | 进度依据 |
| --- | --- |
| 查找字幕和电影来源 | 已结束的查询项数 / 2 项；是否找到资源另看结果提示 |
| 核实各平台弹幕并缓存 | 已结束的来源数 / 本次待查来源数，成功来源需缓存完成才计数；失败也计入已结束数量，是否可用另看结果 |
| 提取内封台词 | FFmpeg 实际输出的字幕时间 / 影片时长；最后一句可能早于片尾，进程成功退出后本步完成 |
| 排列弹幕 | 已检查条目 / 输入条目，包含被去重或限流的条目 |
| 保存字幕 | 已写入 UTF-8 字节 / 总字节；文件关闭成功后才显示本步完成 |
| 写回 NAS | 已复制字节 / 成品总字节；完成发布后才显示成功 |

影片探测、接口等待和解析等没有可用总量时，显示状态和耗时，进度不会随时间自行增加。数据处理到末尾但还在等待进程退出或文件关闭时，暂不显示 100%。更新后请关闭旧窗口，通过原快捷方式重新打开。

## 异地 NAS

NAS 不必和电视、电脑在同一个局域网，但运行工具的电脑必须已经能够读取影片目录并新建字幕文件。例如使用已有的远程文件访问方案，将目录呈现为 Windows 可访问的映射盘或 UNC 路径。

本工具不负责建立 NAS 远程连接，不接收极空间账号。极空间 App 内的虚拟路径或网页分享链接不能直接当作影片路径。初始探测、备用指纹计算及手动内封提取会读取网络文件，耗时取决于网络与视频封装；在线按片名查询不需要读取视频正文。

部分虚拟映射盘能正常读写，却不支持 Windows 的最终路径查询，旧版本可能因此报 `WinError 1005`。2.0.2 已兼容这种情况，保留用户选择的盘符路径继续处理，并继续检查文件是否可读、大小及修改时间是否变化。更新后请关闭旧窗口重新打开。目录改名或映射盘重新挂载后，需要重新选择影片。

## 功能与限制

- 优先读取影片同名 NFO，或单影片目录的 `movie.nfo`；否则清理文件名中的年份、编码和画质标签。
- 对“中文片名 英文片名”形式的文件名，完整搜索无结果时自动尝试中文片名。
- 默认使用同影片的外置 SRT/ASS 和在线中文字幕，内封文字字幕需手动选用。
- PGS/SUP 等图片字幕不能直接合并，需要先 OCR 或补充文字字幕。
- 原字幕样式会重命名以避免冲突；弹幕使用更高 Layer，默认给台词保留底部约 32% 的区域。
- XML/JSON 弹幕默认在顶部 25% 显示，同屏最多 6 条、每条滚动 12 秒、1080p 基准字号 32、不透明度 80%；可调整显示设置和时间偏移。
- 外部 ASS 弹幕保留其排版；双方 ASS 画布分辨率不一致时会提示。
- 弹幕会去重、限流，并按影片时长裁剪；不同剪辑版仍可能需要手动调整时间。
- 识别阶段只写本地缓存；只有确认合成后才写影片目录。发布前检查影片是否发生变化，变化时只保留本地结果。
- 当前标题搜索主要面向电影，不是剧集季数、集数自动匹配工具。
- ASS 效果取决于电视播放器及其字幕渲染器；本仓库的输出尚未完成各电视型号的兼容性测试。
