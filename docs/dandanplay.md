官方文档：https://doc.dandanplay.com/open/

开发者中心：https://dev.dandanplay.com/

## 当前状态

2026-10-08 已在官方开发者中心确认应用审核通过并上线，层级为基础。2.8.0 已接入官方匹配、搜索和弹幕接口。本机凭证已配置并通过真实签名请求验证，不随仓库发布。

## 已接入功能

官方服务器地址：`https://api.dandanplay.net`。

| 功能 | 接口 |
| --- | --- |
| 通过影片特征匹配节目 | `POST /api/v2/match` |
| 通过标题搜索节目 | `GET /api/v2/search/episodes` |
| 获取指定节目的弹幕 | `GET /api/v2/comment/{episodeId}` |

点击主窗口“弹弹play接入”，填写自己的 AppId 和 AppSecret 后保存并验证。已有密钥时留空沿用；取消启用后保存即可停用。配置位于 `%LOCALAPPDATA%/NasDanmaku/dandanplay.local.json`，密钥以 Windows 当前用户 DPAPI 加密，配置覆盖前备份到 `D:/临时备份/NasDanmaku`。非 Windows 可以通过 `DANDANPLAY_APP_ID` 和 `DANDANPLAY_APP_SECRET` 环境变量提供凭证。

认证使用 `X-AppId`、`X-Timestamp` 和 `X-Signature`。签名为 `Base64(SHA256(AppId + Timestamp + Path + AppSecret))`，Path 不含查询参数，使用 SHA256 原始摘要，不发送明文密钥。跨域跳转清除认证头。

## 匹配与候选选择

- 识别影片时只读取前 16 MB 计算 MD5，发送不含目录和扩展名的文件名、文件大小及秒数，不上传视频内容。
- 精确文件关联优先。模糊匹配和标题搜索先核对片名，明显不相符的结果不会进入候选；标题筛选不能证明剪辑版本相同。
- 有多个官方候选时须自行选择具体电影或剧集，不会默认下载第一集。有原平台电影候选时仍可自动查询该电影来源。
- “按此片名重查”直接搜索节目，不再读取视频指纹。官方匹配失败时仍保留原有 B 站直连及第三方公共来源。
- 仅获取当前选中节目的弹幕；请求包含 `withRelated=true`。服务返回的匹配偏移只应用一次，主窗口偏移为额外调整。

## 缓存与错误

匹配和搜索缓存 2 小时，弹幕缓存 6 小时，存于本机 `cache/dandanplay`。请求串行，错误不自动重试。认证失败、限流及空弹幕不缓存；旧的空弹幕缓存也不会阻止用户重试。403/401 提示检查凭证、应用状态和电脑时间；429 提示额度或频率限制。

审核时页面显示日额度 610、月额度 14,640，覆盖所有接口。实际额度和授权范围以开发者中心最新显示为准。保存并验证会发起一次搜索请求。

## 实际验证

2026-10-08 使用本机批准凭证完成签名认证，并从《棺姬嘉依卡》测试集（episodeId `99730001`）真实取得、解析 2,408 条弹幕，验证官方及关联弹幕下载流程。另一个测试节目返回 0 条时明确显示“此节目暂时没有弹幕”。这些测试数据不会作为《楚门的世界》的弹幕使用。

当前网络间歇性连接失败，原影片所在 Z 盘在此次验证环境不可访问，因此尚未完成《楚门的世界》原片的文件指纹匹配及时间轴核验。不能据此认定官方没有该电影资源；原有 B 站来源仍保留。

自动回归覆盖签名、加密保存、缓存、跨域认证头清除、前 16 MB 指纹、偏移、不相关片名筛除及多候选手动选择。回归使用隔离配置和模拟数据；上述下载结果另经真实网络验证。测试不截图、不查看图片。
