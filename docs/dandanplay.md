## 当前状态

2026-10-07 已在官方开发者中心提交申请，后台状态为“审核中”，尚未取得审核通过的应用凭证。当前程序不会调用弹弹play官方在线 API；获取弹幕仍使用 README 中说明的第三方公共来源。

本工具当前为非商业开发与原型验证项目，实际场景为个人 NAS 影片字幕与弹幕合并。申请类别及批准范围以官方审核为准；发布此仓库不表示获得官方授权或背书。

## 拟接入功能

官方服务器地址：`https://api.dandanplay.net`。

| 功能 | 接口 |
| --- | --- |
| 通过影片特征匹配节目 | `POST /api/v2/match` |
| 通过标题搜索节目 | `GET /api/v2/search/episodes` |
| 获取指定节目的弹幕 | `GET /api/v2/comment/{episodeId}` |

具体参数、关联弹幕选项和访问额度以官方现行文档及批准权限为准。取得 AppId 和 AppSecret 后，拟使用官方签名模式，由本机配置提供凭证，不将密钥提交到仓库。

未来界面会明确标注“弹弹play开放弹幕网络”及官网，只有用户主动识别影片时才进行查询，并按照授权额度处理缓存、限流与错误提示。
