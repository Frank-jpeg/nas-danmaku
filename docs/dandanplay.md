## 已接入功能

官方服务器地址：`https://api.dandanplay.net`。

| 功能 | 接口 |
| --- | --- |
| 通过影片特征匹配节目 | `POST /api/v2/match` |
| 通过标题搜索电影目录 | `GET /api/v2/search/tmdb?keyword=...` |
| 获取电影详情与真实节目编号 | `GET /api/v2/bangumi/tmdb-movie-{id}` |
| 通过标题搜索节目 | `GET /api/v2/search/episodes` |
| 获取指定节目的弹幕 | `GET /api/v2/comment/{episodeId}` |

2.8.2 起主窗口“弹弹play”按钮直接显示已启用、已停用、未配置或配置异常。首次使用时填写 AppId 和 AppSecret 后保存并验证；已配置时明确显示“凭证已保存，无需重复填写”，默认收起凭证输入框，点击“修改凭证”才展开。旧密钥不回显，新密钥留空沿用；取消启用后保存即可停用，保留原密钥。读取界面状态不解密密钥、不发起网络请求，不代表已经验证网络连接。

配置位于 `%LOCALAPPDATA%/NasDanmaku/dandanplay.local.json`，密钥以 Windows 当前用户 DPAPI 加密，配置覆盖前备份到 `D:/临时备份/NasDanmaku`。非 Windows 可以通过 `DANDANPLAY_APP_ID` 和 `DANDANPLAY_APP_SECRET` 环境变量提供凭证；界面会标注环境变量优先。

认证使用 `X-AppId`、`X-Timestamp` 和 `X-Signature`。签名为 `Base64(SHA256(AppId + Timestamp + Path + AppSecret))`，Path 不含查询参数，使用 SHA256 原始摘要，不发送明文密钥。跨域跳转清除认证头。

## 匹配与候选选择

- 识别影片时只读取前 16 MB 计算 MD5，发送不含目录和扩展名的文件名、文件大小及秒数，不上传视频内容。
- 精确文件关联优先。模糊匹配和标题搜索先核对片名，明显不相符的结果不会进入候选；标题筛选不能证明剪辑版本相同。
- 有多个官方候选时须自行选择具体电影或剧集，不会默认下载第一集。有原平台电影候选时仍可自动查询该电影来源。
- “按此片名重查”优先查询官方 TMDB 电影目录，过滤电视剧和冲突年份，最多查询 3 部电影的详情，取得真实 episodeId 后按片名和多语言别名核对；无可用结果再搜索节目目录。不会仅凭“节目搜索无结果”判断电影没有官方弹幕。
- 文件匹配请求失败会继续片名搜索，不再直接跳过官方电影查询。原有 B 站直连及第三方公共来源仍保留。
- 仅获取当前选中节目的弹幕；请求包含 `withRelated=true`。服务返回的匹配偏移只应用一次，主窗口偏移为额外调整。

## 缓存与错误

匹配、电影目录、详情和节目搜索缓存 2 小时，弹幕缓存 6 小时，存于本机 `cache/dandanplay`。请求串行，同一失败请求不自动重试。认证失败、限流及空弹幕不缓存；旧的空弹幕缓存也不会阻止用户重试。403/401 提示检查凭证、应用状态和电脑时间；429 提示额度或频率限制。

审核时页面显示日额度 610、月额度 14,640，覆盖所有接口。实际额度和授权范围以开发者中心最新显示为准。保存并验证会发起一次搜索请求。

## 实际验证

2026-10-08 通过 2.8.1 实际电影搜索流程准确命中《楚门的世界》（1998）：电影目录返回 `tmdb-movie-37165`，详情返回真实 episodeId `1000371650001`，官方弹幕接口真实取得、解析 27,448 条官方及关联弹幕，时间覆盖 0–6175 秒。

2.8.0 最初仅接入 `/search/episodes`，普通搜索查不到这部电影，新版节目搜索返回无关动画，遗漏了可用的 TMDB 电影目录。2.8.1 已补齐此流程，无需更换凭证或提升应用层级。此前《棺姬嘉依卡》测试集取得的 2,408 条弹幕仅用于连通性验证。

当前网络间歇性连接失败，原影片所在 Z 盘在此次验证环境不可访问，因此尚未完成《楚门的世界》原片的文件指纹匹配及时间轴核验。不能据此认定官方没有该电影资源；原有 B 站来源仍保留。
