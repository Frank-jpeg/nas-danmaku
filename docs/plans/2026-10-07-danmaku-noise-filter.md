# 垃圾弹幕过滤

用户要求屏蔽刷观看日期/时间、陪谁一起看、重复“在吗”等无关弹幕，并联网参考常用屏蔽规则。保持单 Python 文件，不操作界面，界面效果由用户测试。

## 调研

通过 GitHub 在线搜索并阅读说明：

- https://github.com/jnxyp/Bilibili-Block-List ：按正则与关键词过滤无意义弹幕，区分基础与更强屏蔽。
- https://github.com/Ailitonia/bilibili-danmaku-shield ：包含日期、前排、重复数字/字符等分类；它的其他广泛屏蔽范围不直接采用。
- https://github.com/xmcp/pakku-advanced-filter ：依赖 pakku 的浏览器增强，不适用于这个单文件离线合成工具。

只参考分类，自写针对打卡和闲聊的规则；未复制远程词表。AutoGLM 搜索服务本地未启动，改用 GitHub 公开检索完成资料获取，没有打开浏览器或修改服务。

## 实现

- 内置过滤默认开启：日期/时间打卡、报几刷、陪同观看、找人聊天、重复字母数字、明显广告引流。
- 将 Unicode NFKC、大小写、空格、零宽字符及常见简繁写法规范化后匹配；只改变匹配副本，不改缓存、台词或原评论时间。
- 日期句先提取日期/时间，再判断剩余文字是否属于打卡句式；保留带年份的剧情分析、镜头时间引用、二刷发现伏笔等反例。
- 观看短语分词使用有界动态规划，避免带歧义的重复正则导致指数回溯。
- 自定义关键词按字面包含匹配，每行一个，限 100 条、每条 80 字，总输入最多 10000 字；独立于内置开关，当前窗口有效。
- 过滤先于连续进入和行分配，统计垃圾与关键词屏蔽数量，在合成日志显示。全局总过滤仍包含类型、垃圾、关键词、去重、限流等。
- 已排版 ASS 保留原数据；在线/XML/JSON 在重新合成时过滤。设置示意图不按用户词表过滤，避免示例文字恰好命中而错误拒绝正常设置。

## 验证

仅运行非 GUI 回归。覆盖常见日期和简繁/全角变体、报时、陪同、重复问话、剧情反例、字面关键词、数量限制、长歧义文本、过滤不占进入名额、原字幕不变和合成统计。
