# 垃圾弹幕过滤

用户要求屏蔽刷观看日期/时间、陪谁一起看、重复“在吗”等无关弹幕，并联网参考常用屏蔽规则。补充要求内置规则也显示在自定义列表中，允许查看、修改并解释正则。保持单 Python 文件，不操作界面，界面效果由用户测试。

## 调研

通过 GitHub 在线搜索并阅读说明：

- https://github.com/jnxyp/Bilibili-Block-List ：按正则与关键词过滤无意义弹幕，区分基础与更强屏蔽。
- https://github.com/Ailitonia/bilibili-danmaku-shield ：包含日期、前排、重复数字/字符等分类；它的其他广泛屏蔽范围不直接采用。
- https://github.com/xmcp/pakku-advanced-filter ：依赖 pakku 的浏览器增强，不适用于这个单文件离线合成工具。

只参考分类，自写针对打卡和闲聊的规则；未复制远程词表。AutoGLM 搜索服务本地未启动，改用 GitHub 公开检索完成资料获取，没有打开浏览器或修改服务。

## 实现

- 内置过滤默认开启：日期/时间打卡、报几刷、陪同观看、找人聊天、重复字母数字、明显广告引流。
- 将 Unicode NFKC、大小写、空格、零宽字符及常见简繁写法规范化后匹配；只改变匹配副本，不改缓存、台词或原评论时间。
- 日期句先提取日期/时间，再判断剩余文字是否属于打卡句式；保留带年份的剧情分析、镜头时间引用、二刷发现伏笔等反例。
- 观看短语分词使用有界动态规划，避免带歧义的重复正则导致指数回溯。
- 2.5.0 将六条内置规则和自定义规则统一成数据列表，实际执行直接使用此列表，无隐藏默认回退。用户可改名称、开关、说明、示例和真实匹配字段，可删除、恢复默认；日期和观看组合规则各组成可通过下拉列表编辑。
- 新增规则支持普通关键词、部分正则、去标点整句正则；关键词字面包含匹配，自定义规则独立于内置总开关。最多 150 条、名称 80 字、匹配字段 2000 字。旧 `block_keywords` 调用参数保留兼容，界面改用统一列表。
- 正则/组合规则只检查规范化后不超过 180 字的文本。修改后的正则通过单文件内部参数 `--_filter-rules-worker` 在无窗口子进程匹配；测试限时 3 秒，合成批量过滤限时 15 秒。语法错误、超时明确报错。未改表达式的默认规则和关键词直接执行。
- 编辑窗口提供关键词/正则小抄、屏蔽/保留示例及单句命中测试，显示全部命中规则名称；测试与合成使用同一执行逻辑。点击「保存规则」提交到设置草稿，再「应用设置」校验并保存；取消不改已应用规则。
- 规则及各条开关保存到 `%LOCALAPPDATA%/NasDanmaku/block-rules.local.json`，UTF-8 JSON，最大 512000 字节；Windows 覆盖前备份到 `D:/临时备份/NasDanmaku`。备份/替换失败不应用，空列表可持久化，坏配置提示并暂用默认，不自动覆盖。显示设置与内置总开关仍仅当前窗口有效。
- 过滤先于连续进入和行分配，统计内置与自定义规则屏蔽数量，在合成日志显示。全局总过滤仍包含类型、规则、去重、限流等；统计按首条命中归类。
- 已排版 ASS 保留原数据；在线/XML/JSON 在重新合成时过滤。设置示意图不按用户词表过滤，避免示例文字恰好命中而错误拒绝正常设置。

## 验证

2.5.0 仅运行非 GUI 回归，共 97 项通过。覆盖常见日期和简繁/全角变体、报时、陪同、重复问话、剧情反例、字面关键词、数量限制、长歧义文本、过滤不占进入名额、原字幕不变和合成统计；新增规则修改/停用/删除、组合子项、全部命中名称、坏正则与超时、配置重载/备份、空列表及写入失败保护。未打开规则编辑界面，交由用户测试。
