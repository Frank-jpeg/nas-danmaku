# 弹幕平台选择与显示设置

用户要求增加弹幕来源选择，并参考 B 站设置面板调整字号和显示范围；补充要求默认仅占屏幕顶部 1/4，字号缩小，其他位置不要显示弹幕。

## 实现

- 保留单 Python 运行文件和原桌面快捷方式入口。
- 主界面的电影下拉框旁加入来源下拉框，仅展示该候选已有的平台链接。自动策略不变；指定平台时只在其主/备用服务间回退，失败不使用旧弹幕，也不改选其他平台。
- 在「弹幕设置」独立小窗口提供区域、字号、不透明度、速度、同屏上限、类型屏蔽、防挡字幕与去重开关，含比例示意和恢复默认。避免把所有滑块挤进主窗口。
- 默认顶部 25%、1080p 字号 32、不透明度 80%、8 秒、最多 6 条，固定弹幕关闭；区域内行数不足时自动减少。下方 75% 无弹幕。
- ASS 使用实际坐标、字号及 alpha；所有类型共享行占用。手动开启固定弹幕后仍限制在所选区域，防挡字幕开启时至多顶部 68%。原台词样式保持原样。
- 2.3.1 将同向滚动改成连续进入：入口处留足间距，且整个共同显示区间都不能发生追赶碰撞；按 ASS 厘秒时间与输出坐标判断。按显示时长和同屏上限控制进入间隔，避免批量填满。固定/反向冲突仍独占行。保持原评论时间，拥挤时过滤而不排队延时。
- 仅支持普通滚动、反向滚动、顶部/底部固定。公共接口保留模式用于过滤，不把固定弹幕伪装成滚动。高级特效不支持。
- 字号、区域等显示设置和内置过滤总开关在当前窗口有效，下一次启动恢复默认。2.5.0 屏蔽规则列表及各条开关独立持久化，详见[垃圾弹幕过滤](2026-10-07-danmaku-noise-filter.md)。只在重新合成时应用，不自动修改已有 NAS 成品。外部 ASS 保留排版，禁用显示设置，仅调整偏移。

## 验证

- 回归覆盖指定平台成功/失败、来源列表随候选变化、失败后禁止误用旧数据、字幕与弹幕本地缓存、NAS 写回等流程。
- 排版测试覆盖 720p/1080p/4K 的区域边界、固定与反向弹幕、同屏上限、颜色/类型/重复过滤、速度与透明度，以及原台词样式不变。
- FFmpeg 实际渲染检查弹幕像素未越过顶部 1/4，且不透明度影响实际画面。
- Tk 测试覆盖设置应用后实际生成 ASS、取消不修改设置、错误设置拦截及外部 ASS 控件禁用。
- 电视最终效果依赖播放器 ASS 渲染，尚未实机验证。
- 2.3.1 按用户要求未检查界面，只运行非 GUI 回归；新增连续准入、同屏上限、长短文字追赶、入口尾部间距、反向/固定冲突和原时间保持检查。
