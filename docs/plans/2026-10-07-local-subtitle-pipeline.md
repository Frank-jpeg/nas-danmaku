# 异地 NAS 本地字幕合成

问题：内封中文字幕使旧版跳过在线查询。确认合成后 FFmpeg 扫描远程视频，耗时长且容易超时。

选择：默认使用同目录外挂或按标题查询的在线字幕，先缓存到本机，合成后只写回 ASS。整部视频下载后提取依然需要大量传输，因此不作为默认方案。内封提取保留为显式手动选项。

处理顺序：外挂中文字幕 → 迅雷标题/年份查询 → 射手指纹备用。标题匹配过滤其他电影、冲突年份、分碟字幕和异常时间范围；仍需要用户核对版本，不自动修正台词时间轴。

本地目录使用 Windows LocalAppData，缓存原字幕、弹幕及合成结果。NAS 断线时保留本地成品；重试只核对目标影片并复制，不再次查询和合成。上传用 `.part`，关闭后以不覆盖的方式发布为 ASS。进程重启不自动恢复任务，缓存可手动复用。

验证包括模拟 API、在线标题查询不读取视频、字幕缓存后的离线合成、失败保留、重复发布不覆盖、发布完成前不显示成功和隐藏 GUI 重试。真实网络验证只读影片并在本地生成测试结果，不向影片目录发布测试文件。
