# 多字幕来源备用

用户要求增加字幕网站备用，继续保持单文件和本地合成。采用按需顺序切换：迅雷 → SubHD → 射手指纹 → SubtitleCat。成功后立即停止，不为增加来源数量而重复下载；失败原因记录在当前识别结果中。

SubHD 按正常网页流程读取搜索、详情、准备下载与下载接口，使用独立的临时 Cookie 会话。需要登录、验证码或返回拒绝时停止该源，不绕过验证。SubtitleCat 只取已经生成的中文下载链接，标注可能机翻并放在末位。

压缩字幕包支持标准库 ZIP 和本机 7-Zip 的 7z/RAR。只读取 SRT/ASS 内容，不向文件系统释放压缩包条目；限制总大小与条目数，忽略危险路径、英文和分碟字幕。新增源使用请求超时与查询预算，候选最多尝试三项。

ASSRT 提供网页补选入口。此次 A4K 无法连接、字幕库公开地址返回 404，暂不接入自动下载。网页补选不计为自动来源。

验证覆盖切换顺序、停止后续查询、会话保持、受限下载、机翻标注、归档限制和真实 7z 解码。SubHD 和 SubtitleCat 已用真实电影名称验证下载和解析，测试生成文件仅保存在电脑本地。
