# 本机成品保存目录

用户要求“生成到本机”可自定义保存路径，默认桌面。采用一个目录选择入口：主窗口“调整与生成”显示输出位置并提供“更改目录”；默认读取 Windows 用户桌面位置，支持目录重定向。选择后以现有原子写入及备份机制保存到独立的 `output.local.json`，避免影响显示设置、影片偏移和凭证。取消保留原值，保存失败不更新界面状态，原配置不可读时需要重新选择确认。

无影片合成仍先在本机缓存中完成，再通过临时文件完整发布到所选目录。沿用同名版本保护；发布失败明确报告缓存位置，不创建待写回任务。已选影片的合成与恢复任务继续使用原影片目录。所有测试把桌面替换为临时文件夹，不向真实桌面写入测试成品。

2.13.0 完成，本机 202 项回归通过，包括自定义路径与同名文件、默认桌面、目录丢失/无写权限、备份失败、选择取消与重启保持、原影片写回和小屏布局。真实桌面位置通过 Windows Shell 只读比对验证。
