# 不选择影片时直接生成弹幕版字幕

用户按片名查到了《让子弹飞》的字幕和弹幕，希望不选择影片文件也能生成成品。原实现将合成与写回影片目录共用“已选影片”前置条件，导致已有本机资源仍不能合成。

复用当前合成按钮、排版、缓存和成品操作。没有影片文件时按钮显示“生成到本机”，取得台词和弹幕后即可生成；有影片文件时继续“确认合成并写回”。不增加新对话框或要求制作假视频。

- 无影片时使用所选电影标题和年份（无候选时使用查询标题）生成安全文件名，保存到本次本机缓存目录，继续采用 `-v2` 等后缀避免覆盖。
- 使用已有台词画布和弹幕时间轴，不读取影片、不提取内封，也不根据字幕结束时间猜测片长并截断弹幕。提示用户自行核对电影版本和同步。
- 本机成品作为成功结果显示，支持打开文件夹和复制路径；不加入 NAS 待写回记录，不清除其他待写回任务。
- 缺台词或弹幕时仍不可合成。后选影片保留来源、台词选择和缓存，继续支持按影片签名核对后写回。
- 同步界面、帮助和 README 中此前“合成前必须选影片”的说明。

195 项本机回归通过，覆盖无文件离线合成、文件名与重复生成、保留较晚的弹幕、NAS 待写回隔离、失败不报告成功、隐藏界面生成及后选影片写回。

2026-10-09 在隐藏 Tk 窗口中实际按片名查询《让子弹飞 2010》，取得三份在线字幕和 B 站直连 48,413 条弹幕。点击“生成到本机”，使用本机当前显示设置及过滤规则，得到 2,457 行台词、过滤/限流后 3,568 条弹幕，ASS 重新解析条数一致。生成过程中禁止联网、读取影片签名及 NAS 写回，现有待写回记录前后一致。没有核对真实影片时间轴，不截图、不查看图片。
