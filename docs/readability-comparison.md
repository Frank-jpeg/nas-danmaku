# 弹幕清晰度对比测试

`tools/make_readability_comparison.py` 生成独立的本地测试包，不修改正式软件参数，不读取真实电影。

测试包有 18 个方案：原效果、放大字号、不透明度、三档慢速、同屏减量、加粗描边、白字实心描边、长短句等速、中间停顿、中央减速、固定显示、半透明底框、长句两行、过滤超长，以及慢速与停顿的清晰组合。基础方案使用正式软件的 `render_comments`；分段移动和固定转换仅存在于测试生成器中，还没有成为软件功能。

每段 36 秒，六条相同短句/彩色句/长句每 12 秒输入一轮。三轮依次经过深色、浅色、带移动色块的纹理背景。实际排版会因密度或独占行而过滤评论，画面显示本段条数。停顿和减速方案保守地独占行，避免后续文字追尾；长句换行预留独立的两行区域。截断跨章节的弹幕时保留移动标签原时长，避免截短事件造成加速。

输出包含：

- 10 分 48 秒的顺序轮播 MKV，18 个章节。
- 36 秒的 60 fps / 24 fps MKV，各含 18 条可选 ASS 字幕轨。
- 36 秒的 60 fps MP4，原效果文字已压制进画面，用于辅助判断 ASS 播放器渲染差异。
- 全部方案顺序 ASS、18 个单方案 ASS、使用说明和 JSON 验证记录。

短片帧率不保证等于播放器的字幕动画刷新率。人工背景用于比较，选中方案后仍需在实际影片和目标电视上验证。

## 本机生成

生成器需要 Python、Pillow、支持 libass 的 FFmpeg/ffprobe，以及 Windows 自带的微软雅黑字体。它会将本机字体附到 MKV 供本地播放验证。视频、字体和字幕都留在用户指定目录，不提交到仓库。目标目录必须不存在，以免覆盖历史测试包。

```powershell
python tools/make_readability_comparison.py "D:\测试输出\弹幕清晰度对比" --work work/readability-comparison
```

制作新的对比包时可指定 `--reuse-background` 复用相同工作目录中已生成的背景短片。

## 验证

生成时解析每份 ASS，检查样式引用、事件时长、单一定位标签、章节裁切和三种背景下均有弹幕。分段轨迹检查同一行的预约时间不重叠。每个方案均用 libass 渲染到空输出进行兼容检查，不保存或读取截图；ffprobe 检查分辨率、时长、帧率、字幕轨数和章节数。电视端的字体加载、底框和分段移动仍以实际播放器表现为准。
